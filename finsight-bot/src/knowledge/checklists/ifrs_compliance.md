# IFRS Compliance Checklist

## IFRS 16 - Leases

### Recognition
- [ ] All leases identified (operating and finance)
- [ ] Lease term determined correctly
- [ ] Extension/termination options assessed
- [ ] Variable lease payments identified

### Measurement
- [ ] Lease liability measured at PV of lease payments
- [ ] Discount rate properly selected
- [ ] Right-of-use asset calculated correctly
- [ ] Initial direct costs included

### Presentation
- [ ] Lease liabilities presented correctly
- [ ] ROU assets classified appropriately
- [ ] Interest expense separated

### Disclosure
- [ ] Reconciliation of lease commitments
- [ ] Maturity analysis of lease liabilities
- [ ] Total cash outflow for leases disclosed
- [ ] Leases not commenced disclosed

### Exemptions Applied
- [ ] Short-term leases (<12 months) documented
- [ ] Low-value assets (<$5,000) documented

---

## IFRS 15 - Revenue

### Contract Identification
- [ ] Contract criteria met
- [ ] Contract modifications identified
- [ ] Contract combinations assessed

### Performance Obligations
- [ ] Distinct goods/services identified
- [ ] Series identified where applicable
- [ ] Satisfaction of performance obligations determined

### Transaction Price
- [ ] Fixed consideration included
- [ ] Variable consideration estimated
- [ ] Constrained where necessary
- [ ] Time value of money considered

### Allocation
- [ ] Standalone selling prices determined
- [ ] Allocated correctly to performance obligations

### Recognition
- [ ] Point in time vs over time determined
- [ ] Revenue recognized appropriately
- [ ] Contract assets/liabilities presented

---

## IFRS 9 - Financial Instruments

### Classification
- [ ] Business model assessed
- [ ] SPPI test performed
- [ ] Classification appropriate

### Measurement
- [ ] Initial fair value determined
- [ ] Transaction costs handled correctly
- [ ] Subsequent measurement appropriate

### Impairment (ECL)
- [ ] 3-stage model applied
- [ ] 12-month vs lifetime ECL determined
- [ ] Forward-looking information incorporated
- [ ] Simplified approach applied where appropriate

### Disclosure
- [ ] Credit risk disclosures complete
- [ ] Fair value disclosures complete
- [ ] Risk disclosures comprehensive

---

## IAS 16 - Property, Plant and Equipment

### Recognition
- [ ] Probable future benefits
- [ ] Cost reliably measurable

### Measurement
- [ ] Cost components identified
- [ ] Subsequent expenditure treatment correct
- [ ] Cost or revaluation model applied

### Depreciation
- [ ] Useful life reviewed
- [ ] Residual value reviewed
- [ ] Method appropriate
- [ ] Component depreciation applied

### Impairment
- [ ] Indicators assessed
- [ ] Value in use calculated
- [ ] Fair value less costs to sell determined
- [ ] Reversal considerations made

---

## General Compliance

### Financial Statements
- [ ] Complete set of FS presented
- [ ] All IFRS standards applied
- [ ] Comparative information provided
- [ ] Materiality applied appropriately

### Disclosures
- [ ] Accounting policies disclosed
- [ ] Key judgments disclosed
- [ ] Sources of estimation uncertainty
- [ ] Related party disclosures complete
- [ ] Events after reporting date disclosed

### Presentation
- [ ] Classification appropriate
- [ ] Aggregation appropriate
- [ ] Offsetting rules followed
